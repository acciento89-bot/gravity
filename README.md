# +1 Gravity

A mobile-first Roblox progression game where the visible avatar gains Gravity, pulls increasingly massive objects into a stylized orbit, and collapses the run into permanent Gravity Cores.

## Core loop

1. Gain Gravity every second.
2. Pull nearby objects once their Gravity requirement is met.
3. Earn XP and climb from Level 0 to Level 50.
4. Unlock increasingly dramatic zones and object classes.
5. At Level 50, trigger COLLAPSE.
6. Reset the run to Level 0 / Gravity 0, gain a permanent Core, and earn XP faster next run.

## Product rules

- The Roblox avatar remains visible.
- Center gameplay on the player's orbit silhouette, not pets.
- Rebirth is named **Collapse** and is a diegetic singularity event.
- A Core permanently adds +25% XP gain.
- Mobile, tablet, desktop, and controller are first-class.
- No purchase prompts on spawn.
- Server authoritative progression, economy, collapse rewards, persistence, and purchase receipts.
- Orbit visuals are client-side and capped; progression never depends on hundreds of physics parts.
- No gore, weapons, gambling, fear/horror, drugs, or other content that would raise content maturity unnecessarily.
