# +1 Gravity — Release Metadata / Store-Art Brief

## Canonical experience name

**+1 Gravity**

## Short positioning

Grow your Gravity, pull bigger and bigger objects into orbit, reach Level 50 and Collapse the whole run into permanent Cores.

## Production description — English

Gravity grows every second. Walk near objects and they snap into your orbit — from soda cans and bikes to cars, containers, jet engines and building-scale debris.

Level up, unlock five escalating zones, and reach Level 50 + 5K Gravity to trigger COLLAPSE. Your run resets, you gain a permanent Gravity Core, and future runs earn XP faster.

Features:
- automatic proximity collection — no click spam
- 25 escalating object classes
- Backyard → Downtown → Industrial → Airport → Megacity
- permanent Gravity Cores and Shards
- Orbit and Singularity cosmetics
- daily missions and streak rewards
- Highest Gravity, Total Cores and unboosted Fastest Collapse rankings
- phone, tablet, desktop and controller support
- English / German and Reduced Motion support

Optional purchases accelerate a run or grant cosmetic currency. No purchase prompt appears on spawn.

## Produktionsbeschreibung — Deutsch

Deine Gravität wächst jede Sekunde. Geh in die Nähe von Objekten und sie werden automatisch in deinen Orbit gezogen — von Dosen und Fahrrädern bis zu Autos, Containern, Triebwerken und riesigen Gebäudeteilen.

Steige im Level auf, schalte fünf immer größere Zonen frei und erreiche Level 50 + 5K Gravität für den KOLLAPS. Dein Run wird zurückgesetzt, du erhältst einen permanenten Gravitationskern und sammelst in späteren Runs schneller XP.

Features:
- automatisches Einsammeln in der Nähe — kein Klick-Spam
- 25 immer größere Objektklassen
- Garten → Innenstadt → Industrie → Flughafen → Megastadt
- permanente Gravitationskerne und Splitter
- Orbit- und Singularitäts-Cosmetics
- tägliche Missionen und Serienbelohnungen
- Ranglisten für Top-Gravität, Kerne gesamt und schnellsten ungeboosteten Kollaps
- Smartphone-, Tablet-, Desktop- und Controller-Unterstützung
- Deutsch / Englisch und reduzierte Bewegung

Optionale Käufe beschleunigen einen Run oder geben kosmetische Währung. Beim Start erscheint niemals automatisch ein Kaufdialog.

## Category / audience

- Category direction: Simulator / progression / incremental.
- All-ages target with Minimal content maturity.
- No combat, weapons, blood/gore, gambling, drugs, horror dependency or user-generated text dependency.
- VR disabled unless separately tested.

## Icon brief — 512×512

Single dominant composition. Visible Roblox avatar centered/lower-center with a readable cyan/violet object orbit. Progression joke must be immediate: small can/bike on one side, car/container/large debris on the other. One bright singularity/Core energy focal point. Deep navy world/background, high silhouette contrast, no tiny UI, no fake gameplay, no text required.

The icon must remain readable at small mobile tile size and must not resemble a generic +1 body-growth simulator.

## Thumbnail set — 1920×1080

1. **Core loop:** avatar visibly centered while multiple object scales orbit; Backyard/Downtown transition readable.
2. **Escalation:** large late-game objects (vehicle/container/jet/building chunk) around the avatar in Airport/Megacity, without hiding the character.
3. **Collapse:** truthful gameplay frame during singularity contraction/flash with +1 Core reward presentation.

Optional fourth frame: Style menu with real equipped Orbit/Core cosmetics only.
